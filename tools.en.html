Data Analysis Tools Guide

You can do every week’s data analysis without writing code. Start with Excel to understand the calculations, then use Orange in the second half of the semester to build spectral models by dragging and dropping widgets. If you want to go further, run Python in Colab or Jupyter. All three tools use the same data and should give the same answers.

How to use the Excel practice workbooks

Every workbook has the same layout

  1. Sheet 0 (instructions): learning goals, steps, and the answer-check table.
  2. Sheet 1 (raw data): the same long format as Colab (group, student, item, rep, value…).
  3. Sheets 2, 3…: one sheet per step, with a note beside each formula saying what the function does.
  4. Practice questions: write your answers in the yellow cells and hand them in with your report.

Yellow type or paste · Green formulas, do not edit · Orange results to copy into your report

Switching to the class data

  1. Open the class Google Sheet, select the data (without the header row) → copy.
  2. In the workbook’s raw-data sheet (sheet 1), click A2 → paste. The column order must match the header.
  3. If the class has fewer rows than the example, delete the entire extra rows of old data.
  4. If the student list or number of groups is different, edit the yellow column at the far left of each step sheet.

Cross-check with the Analysis ToolPak (t-test, ANOVA, regression)

The workbooks calculate everything with formulas so you can follow each step. To cross-check with Excel’s built-in tools:

  • Windows: File → Options → Add-ins → at the bottom, “Manage: Excel Add-ins” → Go → check “Analysis ToolPak”. Afterward, “Data Analysis” appears at the far right of the Data tab.
  • Mac: Tools → Excel Add-ins → check “Analysis ToolPak”.
  • The ToolPak produces fixed numbers that do not update when the data change. This is the biggest difference from formulas.
No Excel?
  • Google Sheets: File → Import → Upload the .xlsx. All formulas work, and array formulas are converted to ARRAYFORMULA automatically.
  • LibreOffice Calc (free) can open them too.
  • Numbers on Mac does not support some functions, so please do not use it. If you see #NAME?, your software is too old.

How to use the Orange workflow files

Installation (once only)

  1. Download and install from orangedatamining.com (Windows and Mac available).
  2. Open Orange → Options → Add-ons → check Spectroscopy → OK, then restart Orange. Required for the spectroscopy weeks (from W11).
  3. Download orange_workflows.zip and extract it into one folder (keep the .ows workflow files and the .csv data together).
  4. Orange → File → Open → choose that week’s .ows.

The workflows were made and tested with Orange 3.40 and Spectroscopy 0.9; please use these or newer versions.

Switching to your class data

  1. Double-click the leftmost File widget → click the folder icon → choose your CSV.
  2. In the column table below File, double-click “Role” to set each column: set the Y value (e.g., acidity_pct, oil) to target; set text or ID columns such as sample_id, group, rep to meta; leave the spectral wavelength columns as feature.
  3. Click Apply, and the widgets downstream recalculate automatically.

Tip: if the CSV headers are written as c#acidity_pct and m#sample_id, Orange automatically recognizes them as target and meta. All the example data on this page are set up this way.

The three most common mistakes: ① In the PCA widget, uncheck “Normalize variables” (spectra are only mean-centered); ② connect the score plot to the PCA Data output so you can color points by class; ③ in Test and Score, use “Cross validation by feature → sample_id” so replicates of the same sample are not split apart, otherwise RMSECV is too optimistic.

Colab and Jupyter (advanced)

Colab: no installation

  1. In the weekly overview, click Colab and sign in with your Google account.
  2. Runtime → Run all. The notebook has built-in simulated data, so it runs right away.
  3. To use the class data: follow the “How to use” section in the notebook, either publish the Google Sheet as a CSV link or upload the file.
  4. To keep your own changes: File → Save a copy in Drive.

Jupyter: download to your computer

  1. Install Anaconda (includes numpy, pandas, scipy, matplotlib, scikit-learn) or JupyterLab Desktop.
  2. Download all notebooks + data (zip) and extract it; or click .ipynb in the overview to download a single notebook.
  3. Open JupyterLab, go to the extracted folder → open a notebook in notebooks/ → Run → Run All Cells.

All 13 notebooks were tested in a standard Jupyter environment, so they run completely without Colab.

Study tips for students and teachers

  • Excel first, then Orange, then Python. W1–W8 require only Excel; from W11 only Orange is required; Colab is an advanced option that earns bonus points (see the assessment page).
  • Check your answers with a second tool. Run the same data in two tools; you are done only when the numbers agree. For example, get the RMSEP in Orange for W13, then confirm it in Colab NB11. Being able to explain why the two agree matters more than just pressing buttons.
  • Look at the plot before the numbers. Glance at the box plot, residual plot, and score plot first, then read the p-value and RMSE.
  • One “tool tutor” per group. Take turns; the tutor helps teammates solve software problems, so the teacher only needs to answer the tutor in class.
  • 5-minute warm-up before class. At the start of each week, have students answer one question using last week’s file (e.g., “Why is the CI for G1_S3 especially large?”), which also checks that everyone can open the files.
  • Errors are teaching material too. The example data deliberately include recording errors, outliers, and spectra from the wrong instrument, so students can practice finding them.
