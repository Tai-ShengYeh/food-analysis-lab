第二階段　小組實作卷（40 分，90 分鐘）

你會拿到兩個以你的學號產生的 CSV（長格式：group, student, item, rep, value, unit, temp_C, note, sample）。用 Excel 或 Colab 任選，完成下列任務，交出檔案與一頁結論。每個判定都要寫出引用的數據與門檻。

A 卷　醋的可滴定酸：手動滴定 vs PASCO 自動滴定（8 個醋樣品）

  1. A1　用 3 次 KHP 標定算出 NaOH 濃度 N（平均、SD、RSD）。
  2. A2　用 N、滴定體積、樣品重算出 8 個樣品的手動 % 醋酸（當量重 60.05）。PASCO 的 % 酸已直接給在 pasco_pct_acid。
  3. A3　算 8 個「手動 − 自動」差值的平均與 SD；用 Grubbs 檢定（α = 0.05）判斷有沒有異常樣品，寫出 G 與 Gcrit。
  4. A4　排除異常樣品後，用配對 t 檢定與 Bland–Altman 圖（平均差、95% 一致性界限）比較兩種方法。
  5. A5　三句結論：兩法有沒有系統偏差？方向與大小？可不可以互換？另外說明為什麼相關係數 r 很高卻不能當作「兩法一致」的證據。

B 卷　全班能力試驗與品管（盲樣奶粉）

  1. B1　5 組灰分（各 3 重複）：算各組平均與 SD，做單因子 ANOVA，寫出 F、p 與結論。
  2. B2　以 5 組平均的中位數為指定值、σpt = 0.10%，算各組 z-score 並分級（|z| ≤ 2 滿意、2 < |z| < 3 可疑、|z| ≥ 3 不滿意）。指出哪一組有問題，提出一個可能的實驗原因與下一步。
  3. B3　脂肪 QC 樣品 12 次：以平均 26.0%、SD 0.15% 畫 Shewhart 管制圖，判斷是否違反 Westgard 規則（13s、22s、R4s、41s、10x），寫出違反的規則與第幾點，以及該批數據要不要放行。
  4. B4　蛋白質報告值 ± U（k = 2）對照規格 ≥ 25.0%：判定放行、不放行或無法判斷，並說明理由。若為「無法判斷」，提出實驗室下一步該做什麼。

交叉核對（必做）

從 A3 的 Grubbs G、A4 的配對 t 統計量、B1 的 F 值中任選一個，用第二種方式再算一次（例如 Excel 手算 vs Colab 的 scipy，或公式算臨界值 vs 查表），寫出兩個數字與差異的原因。
