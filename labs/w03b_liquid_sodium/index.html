先想一想
薄鹽醬油真的比較少鈉嗎？
還是只是比較「不鹹」？

薄鹽(減鈉)醬油常用 氯化鉀 KCl 取代部分 NaCl。 「鹹度」來自所有鹽類，「鈉」只算 Na⁺；市售導電度式鹽度計量的是所有離子，Na⁺ 離子選擇電極(ISE)只看 Na⁺—— 兩台儀器對同一瓶薄鹽醬油，會給出一樣的答案嗎？

預測：一般醬油 vs 薄鹽醬油，用 ISE 與鹽度計各量一次，你預期四個數字的大小順序是什麼？先寫在學習單上。

樣品設計：一條濃度階梯

差好幾個數量級——同一種稀釋倍數不可能通用

濃度為一般量級示意，品牌差異很大；實際以各組樣品的營養標示為準。包裝水通常低於量測下限——用來討論「讀不到 ≠ 0」。

原理複習：ISE 量的是什麼？

Nernst：活性每變 10 倍，電位變約 59.2 mV(25°C)

🧲
活性 ≠ 濃度
a = γ·C。醬油離子強度極高、γ 明顯 < 1，原液直接測會偏低；稀釋可讓 γ 接近標準液
🎯
選擇性不是 100%
K⁺ 等陽離子也會少量回應。薄鹽醬油、番茄汁、椰子水 K⁺ 高 → 讀數可能偏高
🧪
pH 範圍
強酸性樣品的 H⁺ 也可能干擾；量測前記下 pH，超出手冊建議範圍要在報告中討論
⚡
鹽度計不一樣
導電度式鹽度計量全部離子的導電度，再假設全是 NaCl 換算——KCl 也被算進「鹽」
Nernst、兩點校正與活性的完整說明請回看 W3 灰分與鈉離子 ↗。

課前作業：稀釋計畫

上課前交——沒有計畫不能上機

  1. 抄下標示：鈉 mg / 每份、每份 mL
  2. 換算原液 Na(mg/L) = 鈉 mg ÷ 每份 mL × 1000
  3. 選稀釋倍數，使預期讀數落在 150–2000 ppm(兩個校正點之間)，最好在 300–1500 ppm
  4. 寫出實際做法：用哪支全量移液管、定容到多少 mL
例：醬油 920 mg / 15 mL → 61,333 mg/L
÷ 50 → 預期讀數 ≈ 1,227 ppm ✓
工具課前稀釋計畫計算器
輸入標示值後按「算稀釋倍數」。
mg/100 mL 還是 mg/100 g？

液體標示用體積，天平量的是重量——用密度接起來

ρ = m(10.00 mL 樣品)10.00 mL
Na(mg/100 g) = Na(mg/100 mL)ρ(g/mL)
  • 用 10 mL 全量移液管取樣，放入已歸零的燒杯，秤到 0.1 mg；二重複
  • 醬油 ρ 約 1.1–1.2 g/mL：若單位搞錯，結果直接差 10–20%
  • 黏稠樣品(醬油、濃湯)流不乾淨：移液管要等滴流時間，或改用直接秤重取樣(重量法更準)
  • 溫度會影響密度與體積，記下室溫

標準添加法 (Standard Addition)

比單點回收率多一步：看斜率

  • 取 4 份相同的稀釋醬油(例如 50× 稀釋液各 10.00 mL)
  • 分別加入 Na⁺ 標準液，使增加量為 0、+200、+400、+600 ppm(加入體積 ≤ 總體積 1%，或全部定容到同體積)
  • 依序量測，畫「讀數 vs 添加量」
  • 斜率 ≈ 1：基質不影響量測
    斜率 < 1：基質壓低回應(離子強度)
    截距：外推得到原樣品濃度
示意數據(非實際結果)：純水加標斜率 ≈ 1.00；稀釋醬油加標斜率 ≈ 0.90。

計算：從讀數到標示單位

讀數 → 原液 → mg/100 mL → mg/100 g → NaCl 當量

C原液(mg/L) = 讀數 × 稀釋倍數
mg/100 mL = C原液 ÷ 10
NaCl 當量 = Na × 2.542
  • 醬油 50× 稀釋，讀數 1,180 ppm
  • 原液 = 1,180 × 50 = 59,000 mg/L = 5,900 mg/100 mL
  • 每份 15 mL → 5,900 × 0.15 = 885 mg/份，與標示比較
  • ρ = 1.18 g/mL → 5,900 ÷ 1.18 = 5,000 mg/100 g
  • NaCl 當量 = 5.90 g × 2.542 ≈ 15.0 g/100 mL

方法比較：ISE vs 導電度鹽度計

同一瓶醬油，兩種「鹽」

  • Na⁺ ISE：只對 Na⁺ 有選擇性，乘 2.542 得「NaCl 當量」
  • 導電度鹽度計(若系上有)：量全部離子，以 NaCl 校正後直接顯示「鹽 %」
  • 一般醬油：兩者應接近(其他離子也會讓鹽度計略高)
  • 薄鹽醬油：KCl 導電 → 鹽度計明顯偏高；ISE 可能因 K⁺ 而略偏高
  • 全班數據畫 Bland–Altman 圖：差值 vs 平均值，看偏差是否隨樣品類型改變
示意數據(非實際結果)：NaCl 當量 g/100 mL。

進階選做：液體樣品的灰分

把今天接回 W3 的核心觀念

  • 取 5.00 mL 醬油到已恆重的瓷坩堝，先在水浴或低溫熱板上蒸乾
  • 抽風櫃內預碳化，再進 550°C 灰化至恆重
  • 算「Na 占灰分的比例」：一般醬油 vs 薄鹽醬油差多少？
注意：醬油含糖與胺基酸，蒸乾時容易起泡噴濺，請先小量預試，必要時加少量去離子水分次蒸乾。灰化本身需數小時，可由助教前一天起爐。
