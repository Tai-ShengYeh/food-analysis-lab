Your role today
If you were the food factory’s QC manager,
would you release product based on this model?
Today is not “just finish the report”: everyone in the audience puts on a skeptical QC manager hat while listening. Is the model’s validation rigorous enough? Where does the error come from? Does VIP pick up real chemical signal, or coincidence? Dare the commercial-sample results be reported responsibly? Everything this semester, from the reference methods of W1–W8 to the spectroscopy and chemometrics of W10–W14, converges in today’s five group presentations.

Today’s format: each group gives a 10-minute talk + 5-minute Q&A, while everyone else completes a peer review form. Each person reviews two groups and writes at least one strength and one specific improvement for each.

Today’s learning goals

After W17 you should be able to…

  • Read a complete model report card, know which fields it must contain, and judge whether it has enough information for a release decision
  • Tell what question each of RMSEC/RMSECV/RMSEP answers, and stop treating training error as prediction error
  • Use VIP against specified bands for a chemical plausibility check to judge whether the model really learned chemical signal
  • State the differences between PLS and NNLS on this problem, and when the non-negativity constraint helps and when it does not
  • Give an honest report of commercial-sample predictions: distinguish “below LOD” from “outside the applicability domain (T²/Q)” and never make up numbers

Presentation format

Each group: 10-minute talk + 5-minute Q&A, 8 required slides

  • 1. Problem and design (5×5 grid, why Y is handled independently)
  • 2. Instrument and calibration records (W10 standards, white reference, cuvette orientation)
  • 3. Preprocessing choice and evidence (RMSECV comparison)
  • 4. Model report card
  • 5. VIP vs specified bands (chemical plausibility check)
  • 6. PLS vs NNLS
  • 7. Commercial-sample results: honest reporting (< LOD / outside applicability domain)
  • 8. Limitations and what you would change next time
These 8 slides are the minimum: you may add slides but not drop any; the order need not be identical, but the logic must flow. Practice putting them in a sensible order in the mini-game shortly.

Common pitfalls

Before presenting, check whether you made any of these mistakes

  • Tuning on the test set: using the test set to pick the preprocessing or number of LV is peeking at the answers (data leakage)
  • Reporting RMSEC as prediction error: RMSEC only shows how well the model memorizes the training data
  • Too many LV: RMSEC keeps falling while RMSECV has long since risen again, which means overfitting
  • Reading VIP as a sign: VIP has meaning only in magnitude; the direction comes from the regression coefficients
  • Treating coincidental correlation as chemical signal: with few samples and many wavelengths, some wavelengths always rise and fall with Y by chance (chance correlation); question any high-VIP band that cannot be matched to a functional group
  • Ignoring sampling variation: the 5×5 design has only 25 blends, and too few replicate measurements can misjudge how good the model is
  • Reporting a number for a commercial sample below the LOD: report “< LOD”; do not write 0 or invent a number
  • Comparing instruments without saying the preprocessing differs: Raman vs NIR, SNV vs raw spectra; when preprocessing differs, RMSEP cannot be compared directly
  • Ignoring the effect of the non-negativity constraint: PLS has no non-negativity constraint and may predict negative values near 0%; NNLS’s c≥0 is more sensible at the low end, but that does not mean it is more accurate over the whole range
