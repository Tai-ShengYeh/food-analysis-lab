Opening question
How many % aspartame is in this powder?
Two completely different calculations: will they give the same answer?
📈
Method A: PLS
Train a statistical model on the 25 “known-ratio” blends the whole class prepared in W15 (each scanned 2 times), then use it to predict unknown samples.
🧮
Method B: NNLS / classical least squares (CLS)
No calibration set at all: just fit the pure-component reference spectra by non-negative least squares and solve for the proportions directly.

Today’s task: Run both routes on the same demo spectra from Colab NB13 (simulated Raman 785), compare which has the smaller prediction error (RMSEP), weigh their pros and cons, and learn when even PLS cannot be trusted.

Two routes: data-driven vs chemistry-driven

Each cell shows the group that prepared that blend: within each group’s 5 blends, each of the 5 aspartame levels appears once and each of the 5 sucralose levels also appears once (W15 ↗).

  • Rotating measurement: 25 calibration bottles (CAL-00…24) + the TA’s 7 blind-sample bottles (BLIND, concentrations between grid points) = 32 bottles, shuffled with Excel =RAND() onto 6 sample racks that rotate through 6 stations (NIR-G1…G5 + Raman 785) → every instrument measures all 32 bottles
  • Replicates: each bottle is re-loaded and scanned 2 times on every instrument, saved separately and not averaged → 50 calibration + 14 blind-sample spectra per instrument
  • Orthogonality check: corr(Yaspartame, Ysucralose) = 0.0000: the two targets are uncorrelated, so the model can tell which is which (Excel: on the 25 blends, use =CORREL(aspartame column, sucralose column))
  • Grouped cross-validation: the 2 spectra of the same bottle are always held out together (grouped by sample_id, 25 folds); otherwise you are peeking at the answer first (W13 ↗). The group column in the uploaded file is the preparation group; do not use it for grouping

The NB13/OR16 demo data = the 50 + 14 spectra from one instrument (simulated Raman 785), in the same format as your uploads; the pure-component reference spectra are reused from W10, the commercial samples from W11, and W15 has no re-measurement.

One model per y? (C2)

PLS1 vs PLS2

1️⃣
PLS1: one model per y
One model for aspartame and another for sucralose, each choosing its own number of latent variables (LV) by RMSECV. Today both picked 4 LV (a coincidence; not always the same).
2️⃣
PLS2: several y share one set of LV
Both y are modeled together and share the same LV. Which is better, PLS1 or PLS2, must be compared with the same grouped cross-validation; you cannot decide from the correlation between the y alone.
In this design corr(Yaspartame, Ysucralose) = 0, but that alone cannot show that PLS2 has no advantage; today we only demonstrate and compare two PLS1 models, with no PLS2 comparison experiment. Latent variables (LV) = the few directions PLS condenses from the whole spectrum that are most related to y (W13 ↗).

Building the second PLS1 in Orange: after finishing aspartame in OR16, double-click File and choose or16_sucralose.csv; leave every other widget unchanged.

Data · Model selection

Preprocessing and number of LV: choose the model by RMSECV (aspartame)

  • Autoscale: PLS by default subtracts the mean and divides by the standard deviation at every wavenumber, so each wavenumber starts on equal footing. Both curves include this step.
  • Blue = mean-centering + PLS default autoscale; orange = baseline subtraction + area normalization first. Compare the lowest points: blue 0.711%, orange 1.306% → choose blue.
  • Lowest at LV = 4 (RMSECV 0.711%); adding more LV makes RMSECV rise again = starting to fit noise (overfitting, W13 ↗).

RMSECV is computed with grouped cross-validation (25 folds; the 2 spectra of one blend are held out together). The sucralose model also picks LV = 4.

Closure (C3)

The three components always add up to 100%

Erythritol % = 100 − aspartame % − sucralose %
Example: aspartame 7.5 + sucralose 5 → erythritol 87.5%
Aspartame %02.557.510
Sucralose %55555
Erythritol %9592.59087.585
  • A little more aspartame means a little less erythritol, always → the erythritol peaks “shrink”, which itself signals “there is more sweetener”
  • So PLS also borrows erythritol bands to predict → those bands get a high VIP (next slide)
  • This is an indirect clue, not aspartame’s own signal; switch the filler to maltodextrin and the clue fails immediately
Chemical cross-check (C3)

VIP vs Raman shift: is the model picking up the “right” signal?

VIP = each wavenumber’s importance for the prediction; VIP>1 = above average (W14 ↗). Good news: the highest point is at the 1000 cm⁻¹ grid point (closest to the ring-breathing mode of the benzene ring at 1003 cm⁻¹, W11 ↗, VIP=2.69): the model relies mainly on the right chemical signal.
Watch out: the erythritol bands (880/1050/1290 cm⁻¹) also have VIP 1.67/1.79/1.45, all above 1. This is the closure from the previous slide: an indirect but real association that becomes unreliable once the filler changes.
How does Method B calculate? (C4)

Least squares: make the sum of (measured − fitted)² as small as possible

Wavenumber123
Pure component A100.2
Pure component B010.5
Unknown sample y0.30.60.36
Try cA=0.3, cB=0.6:
fitted value at wavenumber 3 = 0.3×0.2 + 0.6×0.5 = 0.36 ✓
(measured − fitted)² is 0 at all three wavenumbers → sum = 0, the minimum
  • Least squares: find the coefficients c that make the sum (Σ) of (measured − fitted)² over all wavenumbers smallest; the computer returns exactly c = (0.3, 0.6)
  • Non-negative (NNLS): require c ≥ 0, because a concentration cannot be negative
  • Real spectra: 71 wavenumbers, 3 pure-component references + 1 offset (a baseline raised uniformly across the whole spectrum); the computer does the same thing
  • Do not vector-normalize the reference spectra first: c is converted into proportions using the references’ original heights, and normalizing each one would change the proportions
Method B: NNLS/CLS results (C4)

No calibration set: fit the pure-component spectra directly

Unknown spectrum ≈ c₁·aspartame reference + c₂·sucralose reference + c₃·erythritol reference + offset, c ≥ 0
  • Pro: no calibration set needed; c is each pure component’s relative contribution, with a clear physical meaning
  • Con: assumes spectra are a linear superposition; slight detector saturation, particle size, or baseline differences break the assumption
  • Cannot handle: components missing from the reference library (such as the dextrin in commercial sweeteners); NNLS is forced to fit with only the three references it has
Method (NB13)RMSEP aspartameRMSEP sucralose
PLS1 (LV 4/4)0.557%0.503%
NNLS/CLS (3 components + offset)0.978%0.768%

Same 14 blind-sample spectra. PLS has already “seen” real variation such as slight detector saturation during calibration, so its error is smaller; NNLS does not depend on the calibration range, but it also fails when a new component is not in the reference library.

Approximate LOD/LOQ (C5)

Carry W07 ↗’s 3.3σ/slope rule over to PLS

LOD ≈ 3.3 × σ₀ ÷ slope LOQ ≈ 10 × σ₀ ÷ slope
  • σ₀: SD of the cross-validated predictions for the 10 spectra with 0% aspartame (5 sucralose levels × 2 scans) = 0.7586%, which already includes interference from sucralose
  • Slope: slope of the “predicted vs actual” regression line = 0.9338 (ideal is 1)
LOD = 3.3 × 0.7586 ÷ 0.9338 = 2.68%
LOQ = 10 × 0.7586 ÷ 0.9338 = 8.12%
LOD = the lowest concentration reliably distinguishable from the blank; LOQ = the lowest concentration that can be reliably quantified.

The aspartame LOQ of 8.12% is already close to the 10% upper limit of calibration → only about 8–10% can be formally reported as a number, and most of the range is only “semi-quantitative”. The same applies to sucralose: LOD 2.86%, LOQ 8.67%.

This is a simplified estimate for teaching, not a formal method validation.
Applicability domain (C6)

Does the new sample look like the calibration set? T²/Q from W14 ↗

📏
Hotelling T²: how far from the center within the model
Run PCA on the 50 calibration spectra (mean-centering only) and keep 3 principal components (90.7% of variance explained). Large T² = extreme component ratios, outside the combinations common in the calibration set.
🧩
Q residual: what the model cannot reconstruct
The spectral residual that 3 principal components cannot rebuild. Large Q = something the calibration set never saw (for example a new filler).
T² limit = 3×(50−1)÷(50−3) × F0.95(3, 47)
= 3.128 × 2.802 = 8.765

Q limit (Jackson–Mudholkar) = formula using the variance of the 4th and later principal components = 0.00439

Both limits are 95% upper bounds computed from statistical distributions (same as W14 and NB13), not percentiles of the sorted calibration set. A new sample is outside the applicability domain if T² or Q exceeds its limit.

Commercial tabletop sweetener case (C6·C7)

Label says 1.8%, model says 48.2%: can we report it?

Labeled aspartame1.8% (filler is dextrin, not erythritol)
PLS direct prediction48.2%
Hotelling T²223.6 (limit 8.765, about 26× over)
Q residual3.13 (limit 0.00439, about 713× over)
LOD/LOQ2.68%/8.12%

Dextrin’s spectrum is completely different from the erythritol in the calibration set, so the model is pulled into extrapolating to an absurd 48.2%.

Three gates for honest reporting:
① Check T²/Q first: if both exceed their limits → write “outside the model’s applicability domain; no value reported”
② If it is within the applicability domain: check whether the model’s predicted value is below the LOD of 2.68%; only if the prediction is below the LOD, write “< LOD (2.68%)” per the rule; you cannot conclude “not detected” just because the package label says 1.8%
③ Between LOD and LOQ: you may report a number, but label it “semi-quantitative” and attach the RMSEP
