原理

PCA 在找什麼：變異最大的方向

  • PC1：資料變異量最大的方向；PC2：與 PC1 垂直、次大變異的方向——彼此互相垂直(⟂)
  • PCA 是非監督式(unsupervised)方法——它完全不知道樣品是哪一種油，只根據光譜本身的變異來分
  • 所以如果分數圖上不同油真的分開，代表輸入光譜存在差異；但差異是否真的來自化學組成，還須結合 loadings、原始光譜與量測條件一起確認——等一下也會看到，這個差異也可能只是被一個離群點誤導
原理

分數(score) ＝ loadings 的加權總和

t = p₁(x₁−x̄₁) + p₂(x₂−x̄₂) + p₃(x₃−x̄₃) + …

t＝樣品在這個 PC 上的分數；pⱼ＝第 j 個波長的loading(權重)；xⱼ−x̄ⱼ＝該波長先做完 mean-centering 的值

p=[0.6, 0.6, 0.53]，centred x=[0.5, 0.4, 0.3]
t = 0.6×0.5 + 0.6×0.4 + 0.53×0.3 = 0.30+0.24+0.159 ≈ 0.70
  • loading(負荷量)：每個波長對這個 PC 的「權重」——決定「為什麼」樣品會分開
  • score(分數)：把每個波長的(去平均後)訊號乘上它的權重再加總——就是樣品畫在圖上的座標
  • loading 越大(不管正負)，那個波長對這個 PC 的影響越大；loading 接近 0，代表那個波長幾乎不影響這個 PC

前處理・算一次

中心化(mean-centering)與autoscale算一次

波長原始值 xx − x̄(中心化)÷ SD 後(autoscale)
訊號波長0.8 / 1.0 / 1.2−0.2 / 0 / 0.2−1 / 0 / 1
雜訊波長1.001 / 0.999 / 1.0000.001 / −0.001 / 01 / −1 / 0

兩列都用樣本標準差 SD(算法同 W01 ↗；訊號列 SD=0.2，雜訊列 SD=0.001)。

  • 中心化：三個值各減掉自己的平均值 1.0——這樣 PCA 才是在找「相對平均光譜」的變異，幾乎是必要的前處理
  • autoscale：中心化後再除以自己的標準差——訊號波長跟雜訊波長，中心化後都變成 −1/0/1 這種量級
  • 問題來了：雜訊波長本來訊號很小(SD=0.001)，除完之後卻跟訊號波長一樣「顯眼」——雜訊被放大了，這就是光譜資料通常不做 autoscale 的原因

原理

特徵值(eigenvalue) 與 解釋變異

λₐ ＝ 第 a 個 PC 分數的變異數（eigenvalue）
解釋變異% ＝ λₐ / Σλᵢ × 100%

λₐ 越大，代表樣品在第 a 個 PC 方向上分散得越開——這個 PC 就越「重要」。

  • 今天六種油的資料：PC1 ≈ 46.3%、PC2 ≈ 28.3%、PC3 ≈ 23.0%、PC4 之後只剩 0.53%
  • scree plot(陡坡圖)：把每個 PC 的解釋變異畫成長條圖，用來決定「看幾個 PC 才夠」
  • ⚠️ 這個 λ 跟 W11 ↗ ALS 基線校正用的 λ(平滑度參數)完全是兩件事，只是剛好都借用希臘字母 λ

動手重做一次

移除 PEA-3 後重做 PCA

  • 拿掉花生油第 3 重複這一個點：PC1 = 63.5%、PC2 = 33.2%（比移除前的 28.3%還高，不減反增）、PC3 只剩 0.74%——原本被 PEA-3 一個點撐起的 74% PC2 平方和不見了，剩下的變異重新集中成一個乾淨的方向

數據・Loadings

PC1 Loading：哪些波數驅動了這個主成分

PC1 loading 在約 1655 cm⁻¹(C=C stretching)與約 1265 cm⁻¹(=C–H bending)附近是正值的高峰——這兩個都是不飽和相關的拉曼譜帶，也正好解釋了椰子油(高度飽和)為什麼在 PC1 上差最遠。波段歸屬請視為約略指認，實際樣品仍須以標準品或文獻圖譜比對確認。
正負荷的意思：loading 是正值的波段，強度越高的樣品在這個 PC 的分數也越高；loading 是負值，訊號越強分數反而越低。　兩群重疊怎麼辦：可以看 PC3，或換一種前處理(如二階導數)。
Orange OR12 一步步

從光譜到分數圖與 loadings的實際點法

  • File：把 oil 設成 target；sample_id／group／instrument／rep／oil_zh 設成 meta——數字波數欄留原樣當 feature
  • PCA：取消勾選「Normalize variables」(光譜只做 mean-centering)；預設 2 個成分就是 PC1+PC2，想多看幾個(例如 PC3)把「Components」數字調大即可
  • PCA 的 Data 輸出(不是 Transformed Data)接到 Scatter Plot：x=PC1、y=PC2、Color=oil
  • PCA 的 Components 輸出接到 Spectra：畫成 loading vs 波數(波長)
  • 在 Scatter Plot 上框選看起來奇怪的點 → Data Table 檢視原始數值(就是這樣抓到 PEA-3 的)

Orange 工作流程

從光譜到分數圖與 loadings

下方 Colab／R 程式碼是進階選項——不寫程式，用上一頁的 Orange 步驟就能完成今天的分析。

進階：Colab（scikit-learn，5 行）：

from sklearn.decomposition import PCA import numpy as np X = np.loadtxt("oils_X.csv", delimiter=",") # 每列一條光譜（一個樣品） pca = PCA(n_components=5).fit(X - X.mean(axis=0)) scores = pca.transform(X - X.mean(axis=0)) # scores[:, :2] 拿來畫分數圖

進階：R（prcomp）：

X <- as.matrix(read.csv("oils_X.csv", header=FALSE)) pca <- prcomp(X, center=TRUE, scale.=FALSE) scores <- pca$x[, 1:2] loadings <- pca$rotation[, 1] summary(pca)$importance[2, ] # 各 PC 解釋變異比例

樣品、儀器與安全

六種食用油 × Raman 785 ＋ 各組 NIR

  • 六種油：特級初榨橄欖油、精製橄欖油、大豆油、芥花油、椰子油、花生油——每組全部都要測，各 3 次重複(重新裝填/取樣)
  • Raman 785 nm(輪站量測)：初榨橄欖油若用 532 nm 會有強烈螢光干擾——回想 W10 教訓，今天固定用 785 nm
  • 各組 NIR：依組別使用 Avantes（300–1100／900–1650 nm；600–1100 nm 待到貨）、InnoSpectra NIR-S-G1／T1／T11／R14、NeoSpectra Scanner／Micro Dev Kit／光纖模組 或 Spectral Engines NIRONE S2.0／S2.2／S2.5 其中一台
