原理

PCA 在找什麼：變異最大的方向

  • PC1：資料變異量最大的方向；PC2：與 PC1 垂直、次大變異的方向
  • scores(分數)：每個樣品投影到 PC1、PC2 後的座標——決定它畫在圖上哪裡
  • loadings(負荷量)：每個波長(波數)對某個 PC 的貢獻——決定「為什麼」樣品會分開
  • 解釋變異(explained variance)：這個 PC 佔全部變異的比例；scree plot 就是把它們畫成長條圖
  • PCA 是非監督式(unsupervised)方法——它完全不知道樣品是哪一種油，只根據光譜本身的變異來分——所以如果分數圖上不同油真的分開，代表光譜本身就存在真實的化學差異
前處理

mean-centering 一定做，autoscale 通常不做

➖
Mean-centering（一定做）
每個波長都減去自己的平均值，PCA 才是在找「相對平均光譜的變異方向」，幾乎是必要的前處理
🚫
Autoscale（光譜通常不做）
把每個波長除以自己的標準差，會把那些幾乎只有雜訊的波長放大，反而蓋過真正有用的訊號
🧪
真正重要的是前處理方法
SNV(標準常態變量轉換)、一階/二階導數，能去除散射與基線差異，往往比要不要 autoscale 更關鍵
今天示範的圖表都只做mean-centering，沒有 autoscale——這也是 SpectraView／Orange 的 PCA 節點的預設行為。
Orange 工作流程

從光譜到分數圖與 loadings

Colab（scikit-learn，5 行）：

from sklearn.decomposition import PCA import numpy as np X = np.loadtxt("oils_X.csv", delimiter=",") # 每列一條光譜（一個樣品） pca = PCA(n_components=5).fit(X - X.mean(axis=0)) scores = pca.transform(X - X.mean(axis=0)) # scores[:, :2] 拿來畫分數圖

R（prcomp）：

X <- as.matrix(read.csv("oils_X.csv", header=FALSE)) pca <- prcomp(X, center=TRUE, scale.=FALSE) scores <- pca$x[, 1:2] loadings <- pca$rotation[, 1] summary(pca)$importance[2, ] # 各 PC 解釋變異比例

樣品、儀器與安全

六種食用油 × Raman 785 ＋ 各組 NIR

  • 六種油：特級初榨橄欖油、精製橄欖油、大豆油、芥花油、椰子油、花生油——每組全部都要測，各 3 次重複(重新裝填/取樣)
  • Raman 785 nm(輪站量測)：初榨橄欖油若用 532 nm 會有強烈螢光干擾——回想 W10 教訓，今天固定用 785 nm
  • 各組 NIR：依組別使用 Avantes(900–1700／600–1100 nm)、InnoSpectra NIR-S-G1／NIR-M-R14、NeoSpectra 光纖／Micro Dev Kit 或 Spectral Engines NIRONE 其中一台
  • 椰子油：室溫(約24°C以下)會凝固，需先微溫加熱融化成液態才能量測
🔴
拉曼雷射(532/785nm)
不可直視光源或讓光束射向他人眼睛，依儀器說明配戴適當護目措施
🔥🛢️
熱油與地板濕滑
椰子油只需微溫加熱到液態即可，勿過度加熱；發現油漬溢漏立即擦拭，避免滑倒

數據・Loadings

PC1 Loading：哪些波數驅動了這個主成分

示意數據。PC1 loading 在約 1655 cm⁻¹(C=C stretching)與約 1265 cm⁻¹(=C–H bending)附近是正值的高峰——這兩個都是不飽和相關的拉曼譜帶，也正好解釋了椰子油(高度飽和)為什麼在 PC1 上差最遠。波段歸屬請視為約略指認，實際樣品仍須以標準品或文獻圖譜比對確認。
兩群重疊怎麼辦：可以看 PC3，或換一種前處理(如二階導數)。　跨儀器比較：不同組用不同 NIR，波長範圍與解析度不同，分數圖不一定能直接疊在一起——待會請各組互相對照討論。
