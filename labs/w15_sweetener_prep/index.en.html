The sweetener packet on the table hides a question
The packet says “aspartame” or “sucralose”,
but doesn’t tell you how much was added.

Can spectra (Raman / NIR) plus PLS measure the amount of each of the two sweeteners in a powder at the same time?

Today we design first, not measure first: the task in W15 is to prepare a set of calibration samples “worth learning from”; only in W16 will we build the PLS model and use today’s spectra to predict. How well you prepare today directly decides whether W16 succeeds.

But before you start weighing, one key question needs to be thought through: can we really make a solution and measure it, the way we would measure an ordinary beverage? (The answer is in the next section, “Feasibility limits”.)

Feasibility limits

Why prepare a solid powder instead of making a solution?

💧
A solution won’t work
Aspartame dissolves in water only to about 1%; beverage-level concentrations are far below the limit of detection (LOD) of NIR/Raman (= the lowest concentration that can be reliably distinguished from a blank, W07 LOD/LOQ ↗) → so we prepare a solid powder far above commercial levels.
⚖️
Y comes from weighing, not from the label
Commercial products don’t disclose how much of each sweetener is added; our Y (true value) can only come from the actual weighed mass fraction at preparation — you will practice calculating it in a moment (g6).
🧪
Commercial packets = challenge set
High-intensity sweeteners make up only a small fraction of commercial packets (check the label or the literature for the actual fraction; no fixed number is given here); W16 treats them as an external challenge sample, and the signal may be close to or below the LOD.
🧭
Pilot test = a prerequisite already done
The TA has already prepared 0%, 5%, 10% to confirm that every instrument (Raman / each group’s NIR) can detect a signal, so you can safely do the full 25-point design today.
The language of experimental design

Factors, levels, full factorial design

🎛️
Factor
A variable you change on purpose. There are 2 today: aspartame % and sucralose %. The spectrum changes in response; it is a “response”, not a factor.
🎚️
Level
The set values of each factor. Both factors use 0, 2.5, 5, 7.5, 10% (w/w), 5 levels each.
🧮
Full factorial
Every pairwise combination of levels is run: 5 × 5 = 25 formulations. Every aspartame level is paired with every sucralose level.
⚠️
Erythritol is not a third factor
It is the filler: erythritol = 100 − aspartame − sucralose. Once the other two are set, it is determined and cannot be set independently. Example: 7.5% + 5% → 87.5%.
Further reading: for design of experiments (DOE) see the Food Analysis Statistics site ↗ (DOE chapter).
Comparing two designs

1:1 dilution vs. 5×5 grid: which lets the model tell them apart?

  • 1:1 dilution: (2,2), (4,4), (6,6) — both Y rise together, correlation coefficient r = 1 (W04 correlation coefficient r ↗)
  • When a peak in the spectrum gets stronger, the model can’t tell whether there is more aspartame or more sucralose — the two Y are tied together, which is called confounding, i.e., collinearity between the Y (W13 collinearity ↗)
  • 5×5 grid: every aspartame level is paired with all 5 sucralose levels → the 25 points give corr(Y₁,Y₂) = 0.0000
  • r = 0 means the two Y are uncorrelated, so PLS can separate their individual contributions to the spectrum

Where do the blind samples go?

Blind samples lie between the grid points = testing the model’s interpolation ability

  • The TA prepares 7 extra blind bottles: aspartame 3.55–7.73%, sucralose 1.34–6.14%, all within 0–10% but not on grid points
  • Predicting within the calibration range = interpolation, trustworthy; beyond the range = extrapolation, not trustworthy (W13 interpolation vs. extrapolation ↗)
  • Blind samples must be prepared independently and kept out of the calibration set: off-grid blinds test the model’s interpolation to “concentrations it has never seen”; even if a formulation has the same concentration as some calibration point, as long as it is a freshly, independently prepared new physical sample, it can still verify the reproducibility of preparation and prediction
  • The triangles in the plot are the positions in the NB13 demo data; the actual blind concentrations for this class are kept secret by the TA and revealed in W16
Preparation workflow

Weigh → geometric dilution → sieve → seal

⚖️
Weigh to 0.1 mg
Target total mass per bottle 2.000 g; weigh all three components to 0.1 mg on the analytical balance; record the actual weighed mass, not the target on the recipe sheet — this is the real source of Y.
🥣
Geometric dilution
First mix the smallest component with an equal amount of erythritol until uniform, then add the remaining erythritol in portions — so that a small amount of powder isn’t diluted unevenly by a large amount of filler.
🧂
Sieve to a uniform particle size
Sieve after grinding so all samples have the same particle-size range, reducing differences in light scattering caused by particle size (this is also part of the sampling-variation discussion later).
🏷️
Seal, label, watch for moisture
Fillers such as erythritol absorb moisture: work quickly, seal immediately when done, and label with the formulation ID (e.g., CAL-17) and the preparing group.
Worked example

G5 prepares CAL-17: how big is the weighing error?

  • Target A 7.5%, S 5.0% (total 2.000 g) → weigh 0.1500 g / 0.1000 g / 1.7500 g
  • Actual aspartame weighed: 0.1523 g: first grind with an equal amount of about 0.15 g erythritol, then add the remaining ~1.60 g in portions
  • Finally sucralose 0.0997 g, erythritol 1.7489 g, total mass 2.0009 g
  • Aspartame was overweighed by 2.3 mg = 1.5% of target, about 40 times the balance uncertainty → no need to reweigh, but Y must use the actual value
Balance ±a, a = 0.1 mg (rectangular distribution: any value within ±a is equally likely)

u = a / √3 = 0.1 / 1.732 = 0.058 mg
urel = u / m × 100 = 0.058 / 152.3 × 100 ≈ 0.038%

u = standard uncertainty; a = half-width; m = aspartame mass. The origin of ÷√3 is the same as in the W08 measurement uncertainty budget ↗. Weighing is not the largest source of error — see sampling variation next.

Randomization

Why can’t we measure in concentration order?

  • Instruments drift over time: the lamp warms up, laser power and room temperature change slowly
  • If you measure in order from 0% → 10%, “time” and “concentration” rise together → the model may mistake drift for a concentration signal = spurious correlation
  • Random order spreads the drift across all concentrations, so on average it favors no side
  • Take a white reference every time you change sample racks to pull the drift back (W10 dark current · white reference ↗)

Rotating measurement

Every bottle must pass through every instrument

  • Why rotate? In the old approach, if G3 prepared the whole 5% row and measured only on its own NIR, the aspartame Y seen by that instrument was all 5% — Y had no variation, so no model could be built
  • In W16 each instrument gets its own model: the calibration set must cover all 25 formulations, with blind samples available for validation
  • People stay, racks move: each group stays at its own NIR; the Raman 785 station is run by the TA (laser safety). Example: R1 passes through G1 → G2 → … → G5 → Raman
Time budget (estimate)
Per station: 32 bottles × 2 times = 64 spectra
About 1.5 min per spectrum (≈ 40 spectra/hour)
19 min per slot × 6 slots = 114 min ≤ 115 min
More than 1.5 min per spectrum won’t fit (2 min/spectrum needs 150 min) — if you fall behind, tell the TA right away; don’t cut samples or skip the blind samples on your own
How to measure at each station

Each bottle re-inserted twice, saved separately, not averaged

🔁
Re-insert twice (rep 1, 2)
Pour powder, level it, scan, save; pour it back, reload, scan again. Save the 2 spectra separately, don’t average — same as NB13, 2 spectra per bottle; in W16 cross-validation, keep the 2 spectra of the same bottle on the same side (W13 cross-validation ↗).
🌗
NIR diffuse reflectance
Powder is opaque, so what is measured is the scattered-back light: R = (sample − dark)/(white − dark), then converted to log(1/R) (W10 transmission vs. diffuse reflectance ↗). Raman uses a rotating stage, saving 1 spectrum per loading.
🧴
One 2 g bottle is used 12 times
6 stations × 2 times: after measuring, pour back into the original bottle and cap it immediately; clean the sample cup between bottles. The rotation takes about 2 hours and erythritol absorbs moisture — keep the cap in hand.
🏷️
File name = upload fields
instrument_bottleID_rep, e.g., NIR-G3_CAL-17_rep2; the upload sheet fields sample_id, group (preparing group), instrument, rep are the same as in the NB13 data file.

Pure-component reference spectra (W10) and commercial sweeteners (W11) have already been measured and W16 uses them directly, so there is no need to remeasure today.

RSD and sampling variation

Measure the same bottle several times — how much difference counts as large?

  • RSD = SD ÷ mean × 100%: turns the spread into “a percentage of the mean” (W01 RSD% ↗)
  • Example (illustrative): the same bottle re-inserted 5 times, peak heights 102, 98, 105, 95, 100 → mean 100, SD 3.81, RSD 3.8%
  • Today each station re-inserts only 2 times: SD = |x₁ − x₂| ÷ √2, e.g., 102, 98 → 2.83; it is only reliable when all 32 bottles are viewed together
  • Then compare with between samples: how much does the peak height differ between two adjacent levels (2.5 percentage points apart)? If the SD of re-insertion of the same bottle is already close to that gap, the signal is buried by sampling error
RSD = SDmean × 100%

SD = √[ Σ(x − mean)² ÷ (n − 1) ]
= √[(2²+2²+5²+5²+0²) ÷ 4] = 3.81
Data · sampling variation

Sampling variation is QC data too: Raman vs. NIR

Illustrative data (not this class’s measurements, and not NB13). Each bar = the RSD% of 2 re-insertions of the same bottle on that instrument.
Reading the plot: Raman re-insertion RSD is usually larger than NIR — the laser spot only hits local particles, which matters more when the powder is not uniform; NIR diffuse reflectance each time sees a larger area/depth of powder, so it is more representative.
Sampling error = the small portion taken is not representative (segregation, packing tightness, spot position); instrument error = the instrument itself is unstable (dark current, aging white reference, laser power drift).
