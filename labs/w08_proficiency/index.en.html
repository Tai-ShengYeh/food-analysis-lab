Introduction to measurement uncertainty

Where does the number after ± come from?

  • Uncertainty: a parameter describing the range in which the true value may lie
  • Steps: list the sources → convert each to a standard uncertainty u (standard-deviation form) → combine by root sum of squares into uc → multiply by the coverage factor k to get the expanded uncertainty U
  • If you only know “within ±a” (tolerance, scale graduation): rectangular distribution, u=a/√3
  • k=2 corresponds to about a 95% confidence level
  • Combine by root sum of squares: errors partly cancel, so they cannot simply be added

Statistics Ch06–08 ↗

Carbohydrate: by difference

Why does its uncertainty add up everyone’s errors?

Carbohydrate % = 100 − (moisture % + ash % + protein % + fat %)
ucarb = √( umoisture² + uash² + uprotein² + ufat² )
The difference method has no experimental step of its own — it just adds and subtracts other people’s results. For that reason, the errors of moisture, ash, protein, and fat are all carried into it, combined by root sum of squares (uncertainties cannot be added directly). So carbohydrate is always the item with the largest uncertainty in proximate analysis (moisture, ash, protein, fat, carbohydrate) — today you will see it calculated.
Errors get passed down too: This class’s fat uses the direct Soxhlet (unhydrolyzed) result from W6. The 5-group mean is only 21.28%, versus the dairy reference method Röse–Gottlieb value of 25.7% — about 4.4 percentage points lower. The difference method adds this underestimate straight onto carbohydrate, inflating it to about 44% (database: about 37–38%). This is a method bias, not random error — however small Ucarb is, it cannot cover it.

Grubbs outlier test

Within group (n=3) too weak vs class level (n=5) can detect it

Within group: G3 moisture triplicate

Values: 2.70, 2.74, 3.30% (★ = suspected outlier)

G = |x−x̄| / s = 1.1526

G_crit(n=3, α=0.05) = 1.1543 (computed from the formula, not looked up in a table)

At n=3, Grubbs almost cannot detect anything: the theoretical upper bound of G is (n−1)/√n = 1.1547 — no matter how extreme the outlier, G can never exceed this number. And G_crit (1.1543) is only 0.0004 below the bound, which means with only 3 replicates, nothing can be judged significant unless the other two values are nearly identical — within a group you must rely on checking the records.

What ANOVA asks

Is the between-group difference real, or just shaky hands?

🔁
Repeatability s_r
Spread of repeats by the same person, same instrument, in a short time (within group)
🏫
Reproducibility s_R
Spread that also includes differences between groups/laboratories; s_R≥s_r
➗
F = between-group ÷ within-group
MSB = variance between group means, MSW = variance among replicates within groups; large F → the between-group difference is too large to be explained by repeatability error alone
🎯
p and F_crit
F>F_crit (p<0.05) → significant difference between groups

One-way ANOVA

Repeatability (sr) vs reproducibility (sR): using ash as an example

sR = √(sr² + sL²)
Within-group variance (F-test denominator, MSW)sr = 0.0259% (repeatability)
Between-group variance (related to the F-test numerator, MSB)sL = 0.0545% (between groups/laboratories)
CombinedsR = 0.0604% (reproducibility)
F = MSB / MSWF = 14.24 (F_crit(0.05,4,10)=3.478, p=0.0004)
F is far above the critical value, p<0.05: the differences among the 5 groups’ ash means cannot be explained by within-group repeatability (sr) alone — there is a real systematic gap between groups (different weighing habits, judgment of crucible constant weight…). This is exactly why reproducibility sR must include the between-group variance, rather than looking only at your own group’s replicates.
z-score

Score each group’s protein result with the z-score

z = (xgroup − xassigned) / σpt
  • xassigned = median (robust assigned value) of the 5 groups’ single results = 26.000%
  • σpt = predefined target standard deviation (fitness-for-purpose: the tolerable spread set in advance for the intended use) = 0.40% (not the contaminated class SD)
  • |z| ≤ 2: satisfactory 2 < |z| < 3: questionable |z| ≥ 3: unsatisfactory
  • G4 has z = -3.83, in the unsatisfactory zone — the same group that the class-level Grubbs test flagged on the previous slide, so the two corroborate each other

Illustrative data. If σ_pt is too large, truly problematic groups get “hidden”; if too small, there are too many false flags — set it with the method’s practical precision in mind.

How to read a control chart

Measure the same QC sample once in every run

  • QC check sample: a stable sample with a known value, measured together in every analytical run
  • Center line = historical mean; ±2s warning lines (about 95% of points inside); ±3s action lines (about 99.7%)
  • Westgard 13s: one point beyond ±3s → stop reporting, investigate
  • 22s: two consecutive points beyond 2s on the same side → systematic shift
  • Use the historical baseline for the limits, not the current batch’s own data

Measurement uncertainty budget

Example: protein (Kjeldahl)

Uncertainty sourceRelative standard uncertainty
Weighing0.0115%
Titrant conc.0.3000%
Titration volume0.1155%
Conversion factor 6.380.2715%
Repeatability0.5875%
Combined u_c (RSS)0.7227%
u_c = √(Σ components²) U = k·u_c (k=2)
Combined standard uncertainty u_c = 0.7227% (relative)
Corresponding absolute value u_c(abs) ≈ 0.1879% (at the assigned value 26.000%)
Expanded uncertainty U(k=2) ≈ 0.3758% — this is where the number after ± comes from in a report like 26.0% ± 0.4%.

The standard uncertainty of a rectangular distribution (instrument scale/tolerance) = half-width ÷ √3; components already in standard-deviation form (such as titrant standardization) are used directly.
The repeatability term: each group digested only 1 tube of protein this time (single determination, n=1; see the 8-tube limit in W5), so s_r cannot be estimated from within-group replicates; instead we use 3 replicate determinations (25.95, 26.15, 25.85; illustrative data) that the TA ran on the same milk powder, giving s_r=0.1528%. Because each group reports exactly this one single value, s_r is used directly as the repeatability contribution, with no division by √n (division is only needed when averaging n results; it has nothing to do with the √3 of the rectangular distribution).

Release decision: result ± U vs specification

Back to the opening question: butter 80.3% ± 0.4%, release it?

Guard band rule (used in this course): for an item that must be “≥ spec”, release only when the worst case (result − U) ≥ spec; when the best case (result + U) < spec, do not release; in all other cases (the spec falls inside the result ± U interval) the verdict is cannot decide — retest or negotiate. In this example the worst case 79.90% < spec 80.0%, so even though the point estimate 80.3% is already > spec, the verdict must still be cannot decide — this is exactly why measurement uncertainty matters: it means “conforming” no longer rests on a single number.
How to judge an upper spec limit (≤)

The direction flips

Example: potato chips sodium ≤700 mg/100g, measured 690±20 → worst case 710 > 700, best case 670 ≤ 700 → cannot decide
