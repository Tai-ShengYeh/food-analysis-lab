碳水化合物：差減法

為什麼它的不確定度是所有人的總和？

碳水化合物% = 100 − (水分% + 灰分% + 蛋白質% + 脂肪%)
u碳水 = √( u水分² + u灰分² + u蛋白質² + u脂肪² )
差減法沒有自己的實驗步驟——它只是拿別人的結果做加減。正因為如此，水分、灰分、蛋白質、脂肪各自的誤差都會被帶進來，而且是用平方和開根號合併(不確定度不能直接相加)。所以碳水化合物永遠是proximate 分析中不確定度最大的一項——今天就會實際算給你看。
誤差也會一起被傳下來：本班脂肪沿用 W6 的直接 Soxhlet(未水解)，5 組平均只有 21.28%，比乳品參考方法 Röse–Gottlieb 的 25.7% 低約 4.4 個百分點；差減法把這個低估原封不動加到碳水化合物，碳水被墊高到約 44%（資料庫約 37–38%）。這是方法偏差，不是隨機誤差——U碳水 再小也蓋不住它。

Grubbs 離群值檢定

組內(n=3) 太弱 vs 班級層級(n=5) 抓得到

組內：G3 水分三重複

數值：2.70, 2.74, 3.30％（★＝離群嫌疑）

G = |x−x̄| / s = 1.1526

G_crit(n=3, α=0.05) = 1.1543　（公式算出，非查表）

n=3 時，Grubbs 幾乎測不出來：G 的理論上界是 (n−1)/√n = 1.1547——不管離群值多誇張，G 都不可能超過這個數字。而 G_crit 剛好就卡在這條線附近，代表只有 3 個重複值時，這個檢定實質上永遠判不出顯著。

One-way ANOVA

重複性(sr) vs 再現性(sR)：以灰分為例

sR = √(sr² + sL²)
組內變異 (F 檢定分母, MSW)sr = 0.0259%（重複性）
組間變異 (F 檢定分子相關, MSB)sL = 0.0545%（組間/實驗室間）
合併sR = 0.0604%（再現性）
F = MSB / MSWF = 14.24（F_crit(0.05,4,10)=3.478，p=0.0004）
F 遠大於臨界值，p<0.05：5 組灰分平均值之間的差異，不能只用組內的重複性(sr)來解釋——代表組間存在真實的系統性落差(不同秤重習慣、坩堝恆重判斷…)。這正是為什麼再現性 sR 一定要考慮組間變異，不能只看自己組的重複測定。
z-score

用z-score幫每組蛋白質結果打分數

z = (x組 − xassigned) / σpt
  • xassigned = 5 組單次測定值的中位數(穩健指定值) = 26.000%
  • σpt = 事先訂定的目標標準差(fitness-for-purpose) = 0.40%（不是用受汙染的班級 SD）
  • |z| ≤ 2：滿意　2 < |z| < 3：問題(questionable)　|z| ≥ 3：不滿意
  • G4 的 z = -3.83，落在不滿意區——跟前一頁班級層級 Grubbs 抓到的是同一組，互相印證

示意數據。σ_pt 若取太大會把真正的問題組「藏起來」，取太小又會太常誤判——訂定時要考量方法的實務精密度。

以蛋白質(Kjeldahl)為例

不確定度來源相對標準不確定度

u_c = √(Σ 各分量²)　　U = k·u_c (k=2)
合併標準不確定度 u_c = 0.7227%（相對）
對應絕對值 u_c(abs) ≈ 0.1879%（以指定值 26.000% 計）
擴充不確定度 U(k=2) ≈ 0.3758%——這就是報告 26.0% ± 0.4% 這種寫法裡 ± 後面數字的來源。

矩形分佈(儀器刻度/公差)的標準不確定度＝半寬 ÷ √3；已經是標準差型式的分量(如滴定劑標定)則直接使用。
重複性(repeatability)這一項：本次蛋白質每組只消化 1 管(單次測定，n=1，見 W5 的 8 管限制)，無法再由組內重複的變異估計 s_r；改用助教另外對同一份奶粉做的 3 重複測定(25.95, 26.15, 25.85，示意數據)得到 s_r=0.1528%，因為每組報告的就是這一個單次值，所以直接以 s_r 當作重複性貢獻，不再除以 √3。

放行判定：結果 ± U 與規格

回到開場的問題：奶油 80.3% ± 0.4%，放行嗎？

guard band 規則(本課採用)：對「≥ 規格」的項目，只有當最壞情況(結果 − U) ≥ 規格時才判定放行；當最佳情況(結果 + U) < 規格時判定不放行；其餘（規格落在 結果±U 區間內）判定為無法判斷，需複測或協商。本例最壞情況 79.90% < 規格 80.0%，即使點估計 80.3% 已經 > 規格，仍要判定無法判斷——這正是量測不確定度存在的意義：它讓「合格」不再只靠一個數字說了算。
