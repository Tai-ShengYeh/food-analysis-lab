原理 1

折射計 Brix：折射率 ↔ 可溶性固形物

定義：Brix 是以 20°C 下折射率對應「蔗糖 % (w/w)」所建立的刻度。果汁、糖漿裡除了糖，還有酸、鹽等其他可溶物也會提高折射率——所以樣品的 °Brix ≈ 可溶性固形物總量，不完全等於「純糖含量」，這也是待會要拿柳橙汁跟酚硫酸法總醣互相比較的原因。
溫度補償：現代手持/桌上型折射計多有 ATC(自動溫度補償)，但仍建議在建議溫度範圍內操作。

Bias偏差Σ(ŷ − y) / n平均起來偏高還是偏低（正＝高估）；正負會互相抵銷，所以 Bias ≈ 0 不代表準
MAE平均絕對誤差
Mean Absolute Error		Σ|ŷ − y| / n不管正負，平均每顆差幾 °Brix；最直觀
RMSEP預測均方根誤差
Root Mean Square Error of Prediction		√[ Σ(ŷ − y)² / n ]先平方再平均再開根號，大誤差會被放大；單位也是 °Brix，論文與原廠最常報這個

原理 2

酚硫酸法 (DuBois, 1956)：總醣比色定量

  • 濃硫酸使醣類水解＋脫水，生成呋喃醛衍生物(furfural derivatives)
  • 此衍生物與酚縮合，產生穩定的橙黃色產物，於 490 nm 比色
  • 可測總醣（總碳水化合物），包含蔗糖與寡糖(不像銅還原法只測還原糖)；注意這不是營養標示的「糖」，標示的糖只算游離單醣與雙醣
  • 糖醇不反應(sorbitol、erythritol 等)——待會 g3 遊戲會驗證
  • 不同糖(如果糖 vs 葡萄糖)的莫耳顯色率不同，換標準品會有系統性偏差
  • 顯色非嚴格化學計量，因此一定要有自己的標準曲線

QC

R² 迷思：高 R² 不代表迴歸品質好

殘差 = 實測 A − 迴歸預測 A（示意數據）。若殘差呈弧形而非隨機散佈，代表資料有系統性偏離直線的彎曲(如高濃度略飽和)，即使 R² 很高，也該懷疑線性假設。
  • 本組標準曲線 R² = 0.9994（看起來很漂亮），但殘差在兩端偏負、中間偏正，呈弧形——這就是該檢查而非只看 R²的訊號
  • LOD = 3.3σ/斜率 ≈ 3.50 µg/mL；LOQ = 10σ/斜率 ≈ 10.62 µg/mL（σ 這裡取迴歸殘差標準差，實務上也常直接用多次空白讀值的 SD，原理相同）
  • 低於 LOQ 的樣品讀值只能定性、不宜報定量結果

柳橙汁對照(示意數據)：Brix ≈ 11.5 °Brix　vs　酚硫酸總醣 ≈ 9.5 g/100mL(葡萄糖當量)，差 ≈ 2.0。差距主要來自 Brix 把酸與其他可溶性固形物也算進去，而酚硫酸法只對醣類顯色，加上果糖/葡萄糖等不同糖的顯色率差異也會造成小幅落差。
質量守恆(示意計算，回應開場的 40：1)：

樹液 2%、糖漿 66% → 質量比 = 66/2 = 33 : 1

體積比需乘密度校正：
33 × (糖漿密度1.33 / 樹液密度1.008) ≈ 43.5 : 1

Rule of 86：86/2% ≈ 43 : 1，跟上面算出的體積比一致；影片說的「40：1」只要樹液糖度略高一點(約 2.18%)就能剛好對上——量級吻合，這個說法禁得起質量平衡的驗算。
