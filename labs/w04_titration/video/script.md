# W4 手動 vs 自動滴定 課前導覽：pH 一樣，為什麼酸度不一樣？

| 幕 | 旁白 | 〔畫面〕 |
|---|---|---|
| s0 pH 一樣，酸度不一樣？ | 兩杯飲料，pH 都是 3.5，喝起來卻一杯比較酸。為什麼？ | 兩個手繪杯子，同樣貼著 pH 3.5；右邊那杯冒出「好酸！」，中間一個問號便利貼 |
| s1 pH vs 可滴定酸度 | 因為 pH 只看游離的氫離子；可滴定酸度，算的是所有能被鹼中和的酸，連還沒解離的弱酸也算進去。 | 杯中畫出游離 H⁺（小圓點）與還沒解離的酸 HA（成對）；pH 計只圈住游離的，可滴定酸度的大括號把全部圈起來 |
| s2 先標定 NaOH | 做法是用氫氧化鈉滴定。但氫氧化鈉會吸水、吸二氧化碳，濃度不準，所以先用秤得準的 KHP 標定它。 | 滴定管裝 NaOH；空氣中的 H₂O、CO₂ 箭頭跑進瓶子；天平秤 KHP 0.5105 g → 標定出 N = 0.1006 |
| s3 滴定曲線：緩衝區 | 剛開始滴定，pH 慢慢爬，中間有一段幾乎不動，這是緩衝區；加到一半的時候，pH 剛好等於 pKa。 | 大座標一筆畫出醋酸滴定曲線前半段；緩衝區平台塗淡色；半當量點標 pH = pKa 4.76 |
| s4 當量點與酚酞 | 接著 pH 突然一路往上衝，這就是當量點：加進去的鹼，剛好中和所有的酸。酚酞在 pH 8.2 變粉紅，幾乎就在這裡。 | 曲線在 18.75 mL 直直往上衝；當量點標記；pH 8.2 粉紅虛線；錐形瓶由透明轉粉紅 |
| s5 紅酒看不到粉紅 | 但紅酒本身就是紅的，粉紅色看不出來。這時改用 pH 電極自動記錄，曲線最陡的地方，就是終點。 | 紅酒錐形瓶，粉紅被蓋住打問號；PASCO pH 探棒；一階導數 dpH/dV 峰值落在當量點 |
| s6 算出 % 酸 | 知道用了多少毫升的鹼，就能算出百分之幾的酸。例如這瓶醋，算出來大約是 4.56%。 | 公式 % 酸 = N × V × 當量重 ÷ (W × 1000) × 100，代入 0.1006、15.1、60.05、2.00 → 4.56% |
| s7 r 高 ≠ 兩法一致 | 最後比較手動和自動兩種方法。相關係數高，不代表兩法一致；要看兩者相差多少、穩不穩，這就是 Bland–Altman 圖。 | 左：手動 vs PASCO 散佈圖 r = 0.999；右：Bland–Altman 圖，偏差線與 ±1.96 SD 一致界線，紅酒的點散得較開 |
| s8 兩個終點差多少 | 這週上課，手動和 PASCO 你都會親手做一次。先猜猜看：兩個終點會差多少？ | 手動滴定管與 PASCO 並排；拉遠看全圖；片尾卡「兩個終點，會差多少？」 |
