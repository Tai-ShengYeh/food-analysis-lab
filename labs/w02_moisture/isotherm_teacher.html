第一次使用：在 Firebase 開放「只有您」讀取（約 3 分鐘）
  1. Firebase 主控台 → 專案 my-teaching-tools-517a0 → Authentication → 登入方式 → 啟用 Google。
  2. Authentication → 設定 → 已授權的網域 → 新增 tai-shengyeh.github.io。
  3. Firestore Database → 規則：在 student_events 的規則裡加上下面這行讀取規則（保留原本允許學生寫入的規則，不要整段取代），把 Gmail 換成您的帳號後按「發布」： 
    match /student_events/{doc} {
  // …原本的 create 規則保留…
  allow read: if request.auth != null
              && request.auth.token.email == "您的Gmail@gmail.com"
              && request.auth.token.email_verified == true;
}
  4. 回到這頁按「用 Google 登入」。看到「權限不足」代表第 3 步還沒生效或 Gmail 打錯。
