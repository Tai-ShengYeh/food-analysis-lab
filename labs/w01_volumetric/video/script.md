# W1 容量器具校正 課前導覽：你的吸管，真的放出 10 mL 嗎？

> 約 2 分鐘｜sketch-board（手繪草圖，同 W3）｜觀眾：食品系大學部，第一次上分析實驗｜旁白以 `storyboard.json` 的 `narration` 為準；數字出處見 `facts.md`

| 幕 | 旁白 | 〔畫面〕 |
|---|---|---|
| s0 你的吸管準嗎 | 這支 10 毫升的定量吸管，吸到標線、再放出來，真的剛好是 10 毫升嗎？ | 一支定量吸管一筆一筆畫出（hero），水從下往上吸到標線，放進燒杯；便利貼「真的是 10.00 mL？」 |
| s1 Class A 也有公差 | 玻璃有製造誤差，每個人的手法也不一樣。就算是最高等級的 Class A，也只保證在正負 0.02 毫升以內。 | 鏡頭推近標線：標線上下畫出紅色虛線公差帶 ±0.02 mL；兩個小標籤「玻璃」「手法」；Class A 印章 |
| s2 不讀刻度，改用秤的 | 體積用眼睛讀，很難讀得準；質量卻可以秤得很準。所以我們把水放進加蓋的秤重瓶，用分析天平秤到 0.1 毫克。 | 左：眼睛看刻度（×）；右：分析天平＋秤重瓶，吸管傾斜放水，瓶蓋蓋上，顯示器打出 9.9700 g |
| s3 質量換體積：看水溫 | 接著把質量換回體積。水的密度會隨溫度改變，所以每次都要記下水溫；25 度時，1 毫升的水大約是 0.997 公克。 | 溫度計升到 25.0 °C；手繪密度–溫度曲線往下彎；m ÷ ρw → V 的箭頭 |
| s4 別忘了空氣浮力 | 還有一個小細節：天平是在空氣裡秤的，空氣會把水往上托，讀數會輕一點點，所以要再乘上浮力校正，大約千分之一。 | 秤重瓶周圍畫出往上托的小箭頭；天平讀數旁標「輕一點」；× Fb ≈ 1.001 卡片 |
| s5 代進公式 | 把數字代進公式：這次放出來的水，比 10 毫升多了 0.01，還在允許的範圍內。 | V = m × Fb ÷ ρw，三個數字從前幾幕飛進來，算出 10.010 mL；公差帶上的點落在範圍內，打勾 |
| s6 準確度 vs 精密度 | 不過，只做一次還不夠。每支吸管要重複 10 次：平均離標示有多遠，看的是準確度；10 次散得有多開，看的是精密度。 | 靶心：10 個點一個一個打上；平均點到中心的距離＝準確度；圍住 10 點的圈＝精密度 |
| s7 系統誤差 vs 隨機誤差 | 如果 10 次都偏向同一邊，就是系統誤差，要找出原因來修正；如果忽高忽低，就是隨機誤差，要靠多做幾次來描述它。 | 兩個靶並排：左邊點集中但偏一側（系統誤差，紅色箭頭指向同一方向）；右邊點圍著中心散開（隨機誤差） |
| s8 你那支，準嗎 | 上課時，你會親手校正自己的吸管和滴定管。先猜猜看：你手上的那支，準嗎？ | 拉遠成整張畫布（前面各區變成一張流程圖）；中央卡片「你手上的那支，準嗎？」＋W1 容量器具校正 |

## 術語白話對照（旁白只留這幾個術語）
| 術語 | 白話 |
|---|---|
| 定量吸管 | 只有一條標線、從標線放出固定體積的玻璃吸管 |
| Class A | 玻璃量器最高等級，10 mL 吸管公差 ±0.02 mL |
| 秤重瓶 | 有蓋的小玻璃瓶，加蓋避免水蒸發 |
| 浮力校正 | 補回空氣把水往上托造成的讀數偏輕（約 0.1%） |
| 準確度／精密度 | 準不準（平均離標示多遠）／穩不穩（10 次散多開） |
| 系統誤差／隨機誤差 | 每次偏同一邊、找得出原因／忽高忽低、多做幾次來描述 |

## TTS 改寫（字幕仍用 narration）
