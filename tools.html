Excel 練習檔怎麼用

每一份檔案長得都一樣

  1. 0_說明：學習目標、操作步驟、對答案表。
  2. 1_原始數據：和 Colab 同一種長格式（group、student、item、rep、value…）。
  3. 2_、3_…：一個步驟一張工作表，公式旁邊寫著這個函式在做什麼。
  4. 練習題：答案寫在黃色格子，和報告一起交。

練習檔都用公式算，方便看懂每一步。想用 Excel 內建的工具核對：

  • Windows：檔案 → 選項 → 增益集 → 下方「管理：Excel 增益集」按「執行」→ 勾「分析工具箱」。之後在「資料」索引標籤最右邊會出現「資料分析」。
  • Mac：工具 → Excel 增益集 → 勾「分析工具箱」。
  • 工具箱算出的是固定數字，數據改了不會自動更新，這是和公式最大的差別。
沒有 Excel？
  • Google 試算表：檔案 → 匯入 → 上傳 .xlsx，公式都能用，陣列公式會自動轉成 ARRAYFORMULA。
  • LibreOffice Calc（免費）也能開。
  • Mac 的 Numbers 不支援部分函式，請不要用。看到 #NAME? 表示軟體太舊。

Orange 流程檔怎麼用

安裝（一次就好）

  1. 到 orangedatamining.com 下載安裝（Windows／Mac 都有）。
  2. 打開 Orange → Options → Add-ons → 勾 Spectroscopy → OK，裝完重開 Orange。光譜週（W11 起）一定要裝。
  3. 下載 orange_workflows.zip，解壓縮到同一個資料夾（.ows 流程檔和 .csv 資料要放在一起）。
  4. Orange → File → Open → 選該週的 .ows。

流程檔以 Orange 3.40、Spectroscopy 0.9 製作並測試過，請用新版。

換成本班數據

  1. 雙擊流程最左邊的 File 方塊 → 按資料夾圖示 → 選你們的 CSV。
  2. 在 File 下方的欄位表，雙擊「Role」設定每一欄：Y 值（例如 acidity_pct、oil）設成 target；sample_id、group、rep 等文字或編號設成 meta；光譜的波長欄保持 feature。
  3. 按 Apply，後面的方塊會自動重算。

小技巧：CSV 標題寫成 c#acidity_pct、m#sample_id，Orange 就會自動認成 target、meta。本頁的範例資料都是這樣做的。

三個最常見的錯：① PCA 方塊裡的「Normalize variables」要取消勾選（光譜只做平均置中）；② 分數圖要接 PCA 的 Data 輸出，點才能依類別上色；③ Test and Score 用「Cross validation by feature → sample_id」，同一樣品的重複才不會被拆開，RMSECV 才不會過度樂觀。

Colab 與 Jupyter（進階）

Colab：不用安裝

  1. 在每週對照表點 Colab，用 Google 帳號登入。
  2. 執行階段 → 全部執行。筆記本內建模擬資料，直接就能跑。
  3. 換成全班數據：照筆記本「如何使用」那一段，把 Google 試算表發布成 CSV 連結，或上傳檔案。
  4. 要保留自己的修改：檔案 → 在雲端硬碟中儲存複本。

Jupyter：下載到自己電腦

  1. 安裝 Anaconda（已含 numpy、pandas、scipy、matplotlib、scikit-learn），或 JupyterLab Desktop。
  2. 下載 全部筆記本＋資料（zip）並解壓縮；或在對照表點 .ipynb 下載單一筆記本。
  3. 開 JupyterLab，切到解壓縮的資料夾 → 打開 notebooks/ 裡的筆記本 → Run → Run All Cells。

13 本筆記本都在一般 Jupyter 環境測試過，不需要 Colab 也能完整執行。

給同學與老師的學習建議

  • 先 Excel，再 Orange，最後 Python。W1–W8 只要求 Excel；W11 起只要求 Orange；Colab 是進階選項，完成可加分（見評量說明）。
  • 用第二個工具對答案。同一份數據用兩種工具算，數字一致才算完成。例如 W13 用 Orange 得到 RMSEP，再到 Colab NB11 確認。能說出兩者為什麼一樣，比只會按按鈕更重要。
  • 先看圖再看數字。箱形圖、殘差圖、分數圖先看一眼，再讀 p 值和 RMSE。
  • 每組一位「工具小老師」。輪流擔任，負責幫組員排除軟體問題，課堂上老師只需回答小老師。
  • 課前 5 分鐘熱身。每週開場讓學生用上一週的檔案回答一題（例如「G1_S3 為什麼 CI 特別大？」），順便檢查大家都能打開檔案。
  • 錯誤也是教材。範例資料裡刻意放了記錄錯誤、離群值與換錯儀器的光譜，讓學生練習找出來。
